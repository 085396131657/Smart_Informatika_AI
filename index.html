1. Pengertian Algoritma

Algoritma adalah urutan langkah-langkah logis, terstruktur, dan terbatas untuk menyelesaikan suatu masalah. Algoritma tidak harus langsung berupa kode; algoritma dapat ditulis menggunakan bahasa sehari-hari, pseudocode, atau flowchart.

Contoh kehidupan sehari-hari: membuat teh: siapkan gelas → masukkan teh → tuang air panas → tambahkan gula → aduk → sajikan.
Karakteristik algoritma yang baik

Input: memiliki masukan jika diperlukan. Output: menghasilkan keluaran. Definiteness: setiap langkah jelas. Finiteness: berhenti setelah sejumlah langkah. Effectiveness: langkah dapat dikerjakan secara nyata.

2. Struktur Dasar Algoritma

Urutan (Sequence)

Instruksi dijalankan satu per satu sesuai urutan.

Mulai Input nama Tampilkan "Halo, " + nama Selesai
Percabangan (Selection)

Program memilih tindakan berdasarkan kondisi benar atau salah.

Input nilai Jika nilai >= 75 maka Tampilkan "Tuntas" Jika tidak Tampilkan "Belum tuntas" Akhir jika
Perulangan (Iteration)

Instruksi dijalankan berulang selama kondisi tertentu terpenuhi atau sebanyak jumlah yang ditentukan.

Untuk i dari 1 sampai 5 Tampilkan i Selesai perulangan

3. Pseudocode dan Flowchart

Pseudocode adalah penulisan langkah algoritma dengan bahasa sederhana yang menyerupai kode program. Flowchart adalah diagram yang menggambarkan alur algoritma menggunakan simbol.

Oval

Mulai / selesai

Jajar genjang

Input / output

Persegi panjang

Proses

Belah ketupat

Keputusan / kondisi

4. Variabel, Tipe Data, dan Operator

Variabel menyimpan data yang dapat digunakan program. Contoh tipe data: number (angka), string (teks), boolean (benar/salah).

let nama = "Ayu"; // string let nilai = 85; // number let lulus = nilai >= 75; // boolean let jumlah = 10 + 5; // operator aritmetika let sama = nilai === 85; // operator perbandingan

5. Tahapan Pemecahan Masalah

  1. Identifikasi masalah dan tujuan.
  2. Tentukan input, proses, dan output.
  3. Rancang algoritma menggunakan pseudocode atau flowchart.
  4. Implementasikan menjadi kode program.
  5. Uji program dengan beberapa data.
  6. Perbaiki kesalahan (debugging) dan dokumentasikan hasil.

Laboratorium Praktik Koding

Tulis kode JavaScript sederhana dan lihat hasilnya.

Praktik 1 • Program salam

Ubah kode untuk menampilkan salam dengan nama sendiri.

Output program akan muncul di sini.

Praktik 2 • Program ketuntasan

Ubah nilai atau batas ketuntasan, kemudian jalankan program.

Output program akan muncul di sini.

Praktik 3 • Tantangan mandiri

Buat program yang menghitung luas segitiga. Gunakan rumus: ½ × alas × tinggi.

Petunjuk: ganti nilai luas dengan rumus 0.5 * alas * tinggi.
Catatan keamanan: area praktik ini ditujukan untuk kode JavaScript dasar yang ditulis sendiri. Jangan memasukkan kode dari sumber yang tidak dikenal. Program berjalan di browser perangkat masing-masing.
